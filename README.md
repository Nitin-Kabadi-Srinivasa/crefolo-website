# crefolo.com

The website of Crefolo – playful online English lessons for children (German with English toggle) with a built-in trial-lesson booking.

- **Site:** static pages built with [Astro](https://astro.build) (`src/`)
- **Booking backend:** a Cloudflare Worker (`worker/`) that reads free slots from Google Calendar, creates the calendar event with a Google Meet link and sends the emails through Microsoft 365
- **Hosting:** Cloudflare Workers (free plan), one deployment serves both the pages and `/api/*`

## Editing text and prices

All texts live in two files, one per language:

- `src/content/de.ts` – German (main language)
- `src/content/en.ts` – English

Legal pages: `src/content/legal-de.ts` and `src/content/legal-en.ts`.

Change the text between the quotes, keep the commas, save, and publish (see below). If something is syntactically wrong the build fails with a message and the old site stays online.

Trial-lesson hours, weekdays and how far ahead parents can book are set in `wrangler.jsonc` under `vars`.

## Running locally

Requirements: Node.js (LTS). Everything else is installed with `npm install`.

```bash
npm install
npm run build      # builds the pages into dist/
npm run preview    # serves the site + booking API at http://localhost:8787 (MOCK mode, no real calendar)
```

For design work with live reload: `npm run dev` (pages at http://localhost:4321) together with `npm run api` in a second terminal.

`.dev.vars` holds local settings (`MOCK=1` = fake calendar and no emails). Copy `.dev.vars.example` to get started.

## Publishing

Every push to the `main` branch on GitHub is built and deployed by Cloudflare automatically (see `SETUP.md`). Manual deploy from this folder:

```bash
npm run deploy
```

## Checks

```bash
npm run check                 # type-checks pages and worker
node scripts/snap.mjs pages   # full-page screenshots (desktop + mobile) into %TEMP%\crefolo-shots
node scripts/snap.mjs flow    # clicks through the booking widget against http://localhost:8787
```

## Folder overview

```
src/content/      editable texts (de/en, legal)
src/components/   page sections (Hero, Pricing, Booking, …)
src/pages/        routes: /, /en, /probestunde, /en/trial-lesson, /impressum, /datenschutz, …
src/scripts/      booking widget (browser side)
src/assets/       optimized images (generated by scripts/process-images.mjs)
public/           fonts, favicons, robots.txt, _headers, _redirects
worker/           booking API + daily reminder cron (Cloudflare Worker)
scripts/          one-off helpers (images, screenshots, Google auth, Microsoft test)
```

See `SETUP.md` for the one-time account setup and the go-live checklist.
